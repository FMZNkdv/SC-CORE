# Requirements:
* [Zig 0.16.0 - 0.17.0](https://ziglang.org/download/)
* Skills to work with [Supercell](https://en.wikipedia.org/wiki/Supercell_(company)) games. (Brain?)
  
# Setting up:
1. Download/clone a repository:
   ```bash
   git clone https://github.com/FMZNkdv/SC-CORE.git
   cd SC-CORE
   ```
2. Install Zig:
   ```bash
   sudo pacman -S zig
   ```
3. Run:
   ```bash
   zig run Server.zig -O ReleaseSmall
   ```

# Done!
Now you have a working core of games from [Supercell](https://en.wikipedia.org/wiki/Supercell_(company)).
